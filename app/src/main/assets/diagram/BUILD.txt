Bundled Mermaid 12.2.0 and its KaTeX dependency with esbuild 0.25.12. Runtime is a single IIFE; all diagram lazy imports are compiled into that file. KaTeX CSS and WOFF2 fonts are local assets for embedded Mermaid math. No CDN or network requests are needed. Application-owned entry enforces strict security, source/edge/output limits, and strips source configuration. See OfflineDiagramRenderer.kt and DiagramPolicy.kt.
